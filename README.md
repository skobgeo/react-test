# Product Catalog

Тестовое приложение для ревью и доработки. Проект запускается локально и имитирует каталог товаров с фильтрами, деталкой, созданием, редактированием и бесконечной подгрузкой списка.

Стек:

- React 19
- React Router 7
- Vite
- TypeScript
- React Query
- Axios
- MSW
- CSS Modules
- Biome

Код разложен по Feature-Sliced Design: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```

## Задача

Нужно проревьювить приложение как production-код, найти и исправить намеренно оставленные баги, ошибки обработки состояний, неправильное использование React Query, проблемы в самописном UI-kit, недоработки форм, проблемы архитектуры и UX.

Приложение должно собираться и запускаться, но в нем специально есть ошибки, которые проявляются при работе с фильтрами, созданием и изменением товаров, бесконечной подгрузкой, оптимистичными обновлениями и ответами MSW.

MSW полностью эмулирует backend в dev-режиме, отдельный backend запускать не нужно.
