# Shipment Control

Тестовое приложение для ревью и доработки. Проект запускается локально и имитирует операционный кабинет логистики: список поставок со сложной таблицей, фильтрами, сортировкой, бесконечной подгрузкой, быстрым созданием и детальной динамической формой редактирования.

Стек:

- React 19
- React Router 7
- Vite
- TypeScript
- MobX
- CSS Modules
- Axios
- MSW
- Biome

Код разложен по Feature-Sliced Design: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```

## Задача

Нужно проревьювить приложение как production-код, найти и исправить баги, ошибки обработки состояний, неправильное использование React/MobX, проблемы архитектуры и недоработки UX.

MSW полностью эмулирует backend в dev-режиме, отдельный backend запускать не нужно.
